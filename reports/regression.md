## 5. Reading the report

The decision is **block** when a critical gate fails, on any slice, whatever the whole set did; **hold** when every critical gate passes and the change still lost more records than it won, or the whole set holds fewer within the tolerance, so a person reads the losses and decides; **ship** otherwise. The baseline is the pinned run in `eval/baseline.yaml`; `dataset compare` refuses a pin whose run or dataset no longer match, so a number here is always against the reference the pin names. Costs are at API list prices for the tokens the run used, whatever it was billed to; latency is on the machine named above.

```sh
uv run infra-docs-rag dataset run --generator claude-code --version <name>   # answer every record under a version from eval/versions.yaml
uv run infra-docs-rag dataset compare --candidate dataset-v4-rerank-50-claude-code-84   # this report; exit 1 when the decision is block
uv run infra-docs-rag dataset baseline check                               # the pin against its run and the dataset
uv run infra-docs-rag dataset baseline set --run <run> --note '…'          # make a run the new baseline
```
