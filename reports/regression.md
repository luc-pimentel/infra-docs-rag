**Q:** How do I make an alert wait until its condition has held for ten minutes before it fires?

**Reference:** Add `for: 10m` to the alerting rule. Prometheus then checks at each evaluation that the alert stays active for 10 minutes before it counts as firing; during the wait the element is pending. A rule without `for` becomes active on the first evaluation.

**Baseline** (held): Add `for: 10m` to the alerting rule.[1] The optional `for` clause makes Prometheus wait for a set duration between first seeing a new expression output vector element and counting the alert as firing for it.[1] With `for: 10m`, Prometheus checks on every evaluation for 10 minutes that the alert is still active, and only then fires it.[1] While it waits, the alert is in the pending state.[1] If you leave out `for`, the alert becomes active on the first evaluation.[1]
