## 4. Reading the report

A gate compares one metric: `no-drop` and `no-rise` against the baseline with the tolerance the gate names, `min` and `max` against a fixed value. A critical gate that fails blocks (the command exits 1); the others warn. Retrieval metrics count the labelled in-scope questions, grounding metrics the answered ones among them, abstention the out-of-scope and adversarial sets. Costs are at API list prices for the tokens the run used, whatever it was billed to; latency is retrieval plus the model's time, on the machine named above.
