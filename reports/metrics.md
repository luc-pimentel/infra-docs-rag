## 5. Reading the report

A slice of five records moves by 20% when one record flips, so the per-slice numbers locate a problem and the overall numbers and the gates decide. The matrix thresholds are targets read off this baseline; the four modes the benchmark could not measure (`stale-answer`, `wrong-reading`, `missing-hop`, `fabrication`) now have a number each, from the reader's deprecation and readings questions, the two-passage citation check and the judge's fabricated reading. The reader's relevance and agreement readings are calibrated against the rubric labels in reports/judge.md (stage 15); the gates on them stay loose until that agreement is good.

```sh
uv run infra-docs-rag dataset run --generator claude-code                   # answer every record, judge and read each answer, save eval/runs/dataset-<version>-<generator>/
uv run infra-docs-rag dataset metrics --run dataset-v3-budget-claude-code-84      # this report; exit 1 when a critical gate fails
uv run infra-docs-rag dataset metrics --run <candidate> --baseline dataset-v3-budget-claude-code-84   # the same with the no-drop gates live
uv run infra-docs-rag dataset metrics --list-metrics                        # the names the matrix and the gates can use
```
